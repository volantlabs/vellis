# System Closure

Do not infer whole-system completion from completed slices. Perform a separate closure cycle after
the final planned slice.

## Authority and integration closure

- Reconstruct the complete implementation-bearing authority universe from the current model.
- Confirm every entry has full aggregate planned coverage and conforming implementation status.
- Recheck relationships whose evidence spans slices: identity, shared state, transactions, ordering,
  concurrency, timing, durability, replay, recovery, safety, security, numerical behavior, physical
  effects, compatibility, and selected external contracts where modeled.
- Confirm partial slice contributions close together without gaps, overlap conflicts, duplicate
  authority, or mixed-source state.
- Run every model-derived integration, analysis, simulation, inspection, demonstration, hardware,
  or end-to-end verification required for current claims.

## Runnable boundary

Exercise the project-selected external boundary from a fresh environment. Confirm all intentionally
selected public capabilities are available together and no partial public surface is advertised as
complete. Do not demand a user interface, network service, deployment, device, or packaging form the
model and project did not select.

## Cold reconstruction and subtraction

Give a fresh agent only current project artifacts. Require it to identify the model baseline,
implemented authority, realization decisions, evidence, runnable invocation, remaining non-goals,
and recovery path without prior conversation. Then remove obsolete scaffolding, speculative seams,
duplicate authority, stale planning state, and capability claims unsupported by evidence.

## Complete honestly

Set integration and runnable-boundary status to `conforming`, attach decisive evidence, and create a
final checkpoint only after one complete closure review finds no material issue. Campaign status may
then become `complete`. If any accepted authority remains absent, partial, conflicting, stale, or not
evaluated, keep the campaign open or blocked and state the exact disposition.
